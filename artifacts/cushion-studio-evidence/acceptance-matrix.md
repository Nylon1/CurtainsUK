# Cushion Studio acceptance matrix

This checklist defines the requested outcome. It is not a test-pass report. Record actual command/browser evidence separately, including remaining gaps.

## Individual Cushion Configurator first

- Select a real canonical fabric independently of purchasing curtains; full active catalogue discovery is not restricted to curtain renderer eligibility.
- Square 38/45/50/55/60 cm and rectangle 30×45/38×50 cm controls use finished-cover dimensions. Original fabric width and the owner-confirmed 1000 mm image height govern the preview separately from costing dimensions.
- Front/back inspection shows identical upright artwork with the same visible crop. Editing either side changes one shared placement. No mirrored artwork, rotation for cutting savings, or separate reverse fabric.
- Plain, stripe and directional control fabrics retain their exact identities and original images. Larger products reveal more cloth instead of scaling the motif.
- Unpiped, self-piped and contrast-piped appearances match the seam path. Piping follows its own physical cloth mapping rather than stretching to fit cushion perimeter.
- Placement controls are bounded by available original artwork. Missing repeat or manufacturing evidence stays explicit; selection does not fabricate evidence.
- Cutting diagram distinguishes finished/seam/cut outlines, labelled front/back pieces, upright grain and two non-overlapping reproducible matching cuts. Alignment allowance accounts for registering the motif at the start of the actual cloth.
- Server quote, cutting diagram and workroom instructions identify the same specification revision. No supplier costs or private stock quantities appear in customer-facing payloads.

## Separate Cushion Layout second

- Add configured cushions to a newly authored sofa. Layout changes reference products without mutating fabric, dimensions or manufacturing placement.
- Product editing returns to the Configurator, then updates the intended editable layout item. Purchased snapshots cannot be edited.
- Supported guided placements keep every size grounded after tilt/rotation and within the selected furniture. Duplicate and add operations do not stack products unintentionally or put items into empty space.
- Add/remove/duplicate, simple/balanced/layered presets, compare, undo and reset are usable by touch and keyboard without mandatory dragging.
- Close and room cameras, furniture colours, walls and floors work independently of product selection.
- Source scenes include two-seat, three-seat, corner sofa, armchair, double bed and king/super-king option as agreed. Existing sleeping pillows are explicitly scene furnishings, not the decorative products being sold.

## Remaining complete feature

- Round cushions, bolster body plus end panels, larger decorative bed squares, covers and filled products use supported configurable dimensions; proposed dimensions and extra rates remain explicit until confirmed.
- Landing destination includes Style my sofa, Style my bed, Design my cushion, Refresh my cushions; direct browsing, shoppable sets, guides and curtain coordination.
- Each guide explains an adjustable styling principle with a visual example that opens a relevant real-fabric arrangement.
- Save/return, empty designs, unavailable fabrics, corrupt saved data, stale revisions, cross-tab conflicts and storage failure behave honestly. Persistence scope is stated.
- Individual and set review totals include exact quantities, insert/finish specifications, delivery and dispatch information. Set changes recalculate shared cloth/minimum/order increments; no duplicated discounts or savings.
- Current price, stock, supported options and quantities are revalidated before checkout. Customer acceptance is required if the reviewed amount changes.
- Cushion-only and mixed cushion/curtain orders retain distinct immutable specifications through Shopify reconciliation, paid-event handling, staff review and workroom packets. Existing curtain lifecycle meanings stay unchanged.
- Existing sample service carries the exact selected fabric. Adviser capability copy changes only when the corresponding released route is available.

## Evidence and release

- Separate automated domain/contract checks, actual browser checks, emulated narrow/touch checks and physical iPhone/VoiceOver checks. Never infer physical-device results.
- Check image failures, WebGL failure/context loss and bounded texture disposal; customer specification controls remain usable without a successful 3D render.
- Run appropriate existing curtain/sample/commerce regressions and both protected release checks.
- Record exact source SHA, changed-file manifest, asset provenance/licences, outstanding business decisions and scoped release/rollback instructions. Protect existing live theme and other completed work.
