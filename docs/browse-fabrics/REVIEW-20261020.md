## Customer journey

The image-led introduction leads into visual colour and fabric-price choices. Selection feedback is immediate; removing a selection, removing several chips quickly, clearing a search and resetting cannot restore an old URL selection. Discrete choices use a 100 ms debounce; typed searches retain 300 ms. Existing cancellation and response-generation checks remain.

Each fabric keeps its original identity and destinations:

1. Discover it: photograph close-up, full fabric details and See in My Room where available.
2. Feel it at home: the existing sample action, including its eligibility and session handling.
3. Make it yours: the existing curtain configurator, subject to stock gates.

Ask Jane remains the fabric specialist, with the original fabric-specific adviser handoff. The close-up uses a native modal, keyboard zoom, Escape/Close and focus restoration. Zoom is illustrative, not a physical-scale claim. The larger photograph loads only when requested.

Fiona replaces the customer-facing Naila name and portrait. She is identified as an AI adviser, with an English-woman persona and British English retained. Existing internal identifiers, session storage, consultation routing and enablement flags remain unchanged. On mobile the same consultation panel moves after the results in DOM and keyboard order; desktop keeps it alongside.

## Example curtain price

Cards and close-ups show a pair for **200 cm total track width and 200 cm finished drop**, pencil pleat, standard lining, no interlining. This is not 200 cm per panel or a glass measurement. The total includes VAT once, excludes delivery and hardware, and remains an illustration rather than an order or quote token.

The server uses the active production making rules, actual fabric width and repeat evidence, and the same approved supplier-price selector as checkout. It does not multiply the public fabric guide to guess a curtain total. Missing or unsupported evidence displays “Price on configuration”. Existing availability gates still govern purchasing.

Approved price history is read in batches for at most 48 fabrics, with paginated promotion history and a bounded timeout. Price-read failure does not take browsing offline. No supplier costs enter the public card shape. No migrations, prices, discounts or checkout rules are changed.

The existing price bands still filter the fabric guide per metre, not the illustrative curtain total. The UI states that distinction.
