# FIXED140_SINGLE_WIDTH_V1 production contract

The dormant V1 source is the unchanged `fixed140_wave_core.mjs` Git blob `49b1305cdca9925a33480635e3868b0e05242d10` from experimental HEAD `5b4b792432013a867e82956e1bcccfde8cd0778d`. Its SHA-256 is `9a7dfb1c474d0a672a72bbf2f51b160ba976b28b868c5c1c695a91ad2e78b0fa`. Changing its geometry, UVs, or source rules requires a new renderer profile. The six-width binary fixtures and frozen visual comparison are in `tests/room-visualiser/fixtures`.

The pair is 140 cm finished by 120 cm drop. Each 70 cm panel has five Waves at 14 cm finished pitch. The two panels have 11,050 vertices and 21,120 triangles with identical topology and vertex order at every supported fabric width. Each panel uses one supplier image representing one usable physical fabric width. For widths up to 140 cm, the full width is represented; wider sources use a centred physical 140 cm interval. Actual fullness is `min(usableWidthCm, 140) / 70`. X and Y use the same `imageWidthPx / usableWidthCm` scale. There is no horizontal extension, panel join, resampling, or vertical extension. Insufficient source height is unavailable.

`fixed140-assignments.json` is the sole explicit V1 publication registry and is **empty in this release**. Existing approved assets always route to STANDARD, including when a conflicting V1 assignment is present. A V1 assignment later requires an approved, hash-addressed source, its measured dimensions, and its usable physical width. Failed validation returns NOT_ELIGIBLE. Standard customer HTML, viewer modules, and versioned asset pack are unchanged; the V1 page and renderer have their own versioned static pack and are loaded only for a valid explicit assignment. There is no public `?renderer=` or debug profile override.

The V1 Room, Curtain, and Full Curtain controls change only the fixed camera. They keep the same mesh and texture objects. The local-only smoke harness serves the packaged production modules with a fixture image on loopback, without modifying the catalogue or making a public fixture route. No V1 fabric may be enabled until a separate publication review validates real source coverage, artwork, and customer views.
