## First-party transport

`/apps/curtainsuk-decision/jane` maps to a **separate static** Next route, outside the shared commerce/Naila `[operation]` handler. Every request verifies Shopify's signed app-proxy query, the exact allowed shop and path, a fresh timestamp, and a nonempty numeric `logged_in_customer_id`. The customer must also be on a server-side synthetic test allowlist. A domain-separated server HMAC maps the signed shop/customer pair to a stable advisory UUID without storing the raw ID in the consultation. GET supplies a ten-minute HMAC CSRF token. POST requires a storefront Origin, that token, JSON under 16 KB, and an advisory command; the ownership-transfer `recover` action is denied on this channel. A distributed advisory rate limit applies before session operations. Existing encrypted advisory RLS, durable locks, idempotency, limits and spending caps are reused.

The route returns 404 unless it is a Vercel **preview** with the advisory switch on and `ADVISORY_SHOPIFY_APPROVED_COMMIT` exactly matching `VERCEL_GIT_COMMIT_SHA`. It accepts only the existing Supabase project, advisory schema and dedicated trial login. The canonical catalogue key is server-only and is permitted here solely in the protected test boundary. `ADVISORY_SHOPIFY_PROVIDER=mock` makes no model calls. The OpenAI option additionally needs an explicit paid approval reference, a durable evaluation-run UUID, a server-side key and the existing run/session spending caps. Neither option is configured or deployed by this commit.

The theme reads the exact `jane_fabric` URL identity through the governed retail catalogue before displaying it. Sharing it with Jane requires a separate checkbox and sends the existing `customer-notes` context contract. A fabric ID alone never proves current price or stock. Message text is rendered through `textContent`, and a failed send retains the customer's draft and idempotency ID. Jane's returned retail cards display only canonical CurtainsUK profile URLs and approved Shopify CDN images; an exact same-ID Room Visualiser link appears only when present in the governed card. When a sample is eligible, the profile link says it includes sample options. The room offers verified Browse Fabrics, Fabric Intelligence, Room Visualiser and Curtain Style links in a new tab so the conversation remains open. The browser stores only an owner-scoped session UUID to reopen the same conversation. Cross-device continuity needs a reviewed customer-owned listing or recovery design before public launch.
